# 花火職人 (Hanabi Shokunin) · 5×5 呼吸燈動態與開局版圖系統

雙人立體博弈桌遊《花火職人》專用之動態展示與開局棋盤系統。

🌐 **線上靜態網站**：[https://finally1000.github.io/bg-hanabi-shokunin/](https://finally1000.github.io/bg-hanabi-shokunin/)

---

## 🌟 特色功能

1. **iPad Air 4 螢幕 1:1 實體對齊**：
   - 每格精確對應實體 $3.0\,\text{cm}$、黑邊 $0.2\,\text{cm}$。
   - 橫向全螢幕時精確滿版貼合 iPad Air 4 短邊（$15.78\,\text{cm}$）。
   - 內建 3.0cm 螢幕實體對照標尺與縮放微調。

2. **沉浸式全螢幕與自動收折 HUD**：
   - 背景純黑無邊界。
   - 浮動選單閒置 3 秒自動淡出，輕觸螢幕立即喚醒。

3. **呼吸燈時長雙滑桿微調**：
   - 漸變時間（Fade: 0.2s ~ 3.0s）與定格時間（Hold: 0.5s ~ 5.0s）即時調整。

4. **🎲 遊戲開局版圖模式**：
   - 中央格自訂顏色（預設紅色）。
   - 其餘 24 格隨機產生精確 12 個黃色與 12 個藍色。
   - 支援點擊盤面方格手動更換顏色。
